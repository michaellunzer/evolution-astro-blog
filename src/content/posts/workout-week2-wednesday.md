**WEDNESDAY: DELTOIDS AND BICEPS**

■ Dynamic Warm-Up

■ Do an [Ab Program](/ab-program)

*This is the [Week 1 Wednesday](/workout-week1-wednesday/) workout, with the rest between sets cut down to 50 seconds.*

**■ Circuit 1:** This couplet set is performed with little or no rest between each set until both exercises are completed.

### Seated Dumbbell Overhead Press
<img src="/exercises/seated-dumbbell-overhead-press.gif" alt="Seated dumbbell overhead press demonstration" width="200" loading="lazy" style="background:#fff;border-radius:8px;padding:6px" />

Sets of 20, 15, 12, 10, 5, 8, and 16 reps; weight will be moderate, so that you can get all of the reps with good form.

### Seated Dumbbell Two-Arm Curl
<img src="/exercises/seated-dumbbell-two-arm-curl.gif" alt="Seated dumbbell two-arm curl demonstration" width="200" loading="lazy" style="background:#fff;border-radius:8px;padding:6px" />

Sets of 20, 15, 12, 10, 5, 8, and 16 reps; weight will be moderate, so that you can get all of the reps with good form.

Rest 50 seconds and then repeat circuit until done.

**■ Circuit 2:** This couplet set is performed with little or no rest between each set until both exercises are completed.

### Plate Front Raise
<img src="/exercises/plate-front-raise.gif" alt="Plate front raise demonstration" width="200" loading="lazy" style="background:#fff;border-radius:8px;padding:6px" />

12 to 15 reps; weight will be light to moderate, so that you can get all of the reps with good form.

### Standing Barbell Curl
<img src="/exercises/standing-barbell-curl.gif" alt="Standing barbell curl demonstration" width="200" loading="lazy" style="background:#fff;border-radius:8px;padding:6px" />

10 to 12 reps each arm.

Rest 50 seconds and then repeat circuit. Do this 4 times. Push yourself to stay at the same weight, or slightly increase the weight on each set.

**■ Circuit 3:** This couplet set is performed with little or no rest between each set until both exercises are completed.

### Dumbbell Lateral Raise
<img src="/exercises/dumbbell-lateral-raise.gif" alt="Dumbbell lateral raise demonstration" width="200" loading="lazy" style="background:#fff;border-radius:8px;padding:6px" />

12 reps; weight will be moderate, so that you can get all of the reps with good form.

### Dumbbell Hammer Curl
<img src="/exercises/dumbbell-hammer-curl.gif" alt="Dumbbell hammer curl demonstration" width="200" loading="lazy" style="background:#fff;border-radius:8px;padding:6px" />

12 reps; weight will be moderate, so that you can get all of the reps with good form.

Rest 50 seconds and then repeat circuit. Do this 4 times. Push yourself to stay at the same weight, or slightly increase the weight on each set.
